## 🟡 5. Searching Algorithms

Searching algorithms help locate elements in a collection of data.

### Linear Search

Checks elements one by one until the target is found or the collection ends.

- Best TC: O(1)
- Average/Worst TC: O(n)
- Auxiliary SC: O(1)

### Binary Search

Repeatedly divides a sorted search space into halves to find the target.

- Best TC: O(1)
- Average/Worst TC: O(log n)
- Iterative auxiliary SC: O(1)

**Additional topics:**
- First and last occurrence
- Lower and upper bounds
- Search insertion position
- Binary search on answer
- Searching in rotated sorted arrays
- Search in two-dimensional matrices

**Goal:** Choose the right searching strategy based on the data and problem constraints.

## 🟡 6. Sorting Algorithms

Sorting arranges data in ascending or descending order.

| Algorithm | Best TC | Average TC | Worst TC | Auxiliary SC |
|---|---|---|---|---|
| Bubble Sort | O(n)* | O(n²) | O(n²) | O(1) |
| Selection Sort | O(n²) | O(n²) | O(n²) | O(1) |
| Insertion Sort | O(n) | O(n²) | O(n²) | O(1) |
| Merge Sort | O(n log n) | O(n log n) | O(n log n) | O(n) |
| Quick Sort | O(n log n) | O(n log n) | O(n²) | O(log n) average |

*Bubble Sort's best case assumes an early-stop optimization. Quick Sort's auxiliary space is typically O(log n) on average and O(n) in the worst case.*

**Topics covered:**
- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort
- Counting Sort
- Radix Sort
- Sorting stability
- In-place sorting
- Time and space complexity comparison

**Goal:** Understand sorting strategies and their performance trade-offs.
